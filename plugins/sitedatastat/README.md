# 站点数据统计

插件 ID：`sitedatastat`，版本：`1.2.0`。

复用 MoviePilot「站点管理」的用户数据采集和站点适配，提供上传、下载、分享率、魔力、做种统计及历史趋势。插件不再维护独立的站点解析器。

## 数据更新

- 启用或升级插件时，直接同步站点管理已有的最新成功数据，无需重新登录或重抓站点。
- 站点管理手动刷新或定时采集完成后，插件通过 `SiteRefreshed` 事件同步数据，不额外请求站点。
- 插件自己的定时任务和「立即运行一次」调用 `SiteChain.refresh_userdata()`，与站点管理使用同一套采集、适配及核心数据存储；核心升级和站点工具箱的核心适配修复会同时生效。
- 核心采集失败或未返回有效用户信息时按配置重试；最终失败优先沿用核心最后成功数据，其次沿用插件已有快照，并保留原采集时间和失败原因。鼠标悬停在站点名称上可查看。
- 成功采集的做种数为零时如实展示，保持与站点管理一致。

## 历史与展示

原有每日快照、最近两次快照的增量、趋势图、明细表和通知继续保留。切换前的历史快照不重写，日期索引最多保留 90 天。切换当天的增量可能包含新旧采集结果的差异。

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 启用插件 | 关 | 启用定时任务和站点管理刷新后的自动同步 |
| 立即运行一次 | 关 | 保存后使用核心采集流程刷新所选站点 |
| 失败重试一次 | 开 | 核心采集失败后重试一次 |
| 采集周期(cron) | `30 8 * * *` | 使用核心流程主动刷新用户数据 |
| 采集站点 | 空=全部 | 仅统计启用且选中的站点，自动同步也遵守此筛选 |
| 采集后通知 | 不发送 | 插件主动采集后发送今日增量或累计全量；被动同步不发通知 |

现有配置无需迁移。Cookie、API Key、代理等均由核心站点管理统一处理。

## 验证

在包含 `pytest`、`pytz`、`APScheduler` 的 Python 3.11+ 环境运行：

```sh
python -m pytest -q tests/test_sitedatastat.py
```

测试使用隔离的插件存储和核心边界，覆盖两个插件目录的初始化同步、事件同步、核心刷新、失败重试与回退、真实零做种、历史和图表兼容。
