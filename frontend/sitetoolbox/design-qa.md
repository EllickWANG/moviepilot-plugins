## 实际交互验证

- 名称 / 域名搜索、大小写与空白处理、无结果提示、清除筛选、状态过滤、分页。
- 单站复测后显示运行进度，运行期间禁用重复提交；完成后自动刷新并恢复操作。
- 统一阈值从 3 天改为 1 天时，两个失败站点立即进入确认异常筛选；固定时刻及下次运行同步更新。
- 阈值 0 被拦截；关闭有修改的表单时可继续编辑或放弃，取消不会保存。
- 监控计划、范围与策略、高级适配三个表单页可使用；34 站点选择使用计数展示。
- 扫描后存在一项确认、一项待观察；取消清理无影响，确认清理只移除确认项并保留待观察项，随后清理按钮禁用。
- 修复失败有明确反馈；运行记录及系统错误可查看、按来源搜索。
- 深浅主题、手机详情 / 设置滚动、焦点返回、平板列表；390 / 1024 / 1487 px 均无页面横向溢出。
- 发布包通过宿主共享 Vue / Vuetify 加载两个入口，配置保存后页面读取新阈值。

## 有意保留的差别

1. 顶部品牌、全站导航及用户菜单属于 MoviePilot 宿主；本地入口使用标注“演示数据”的预览栏，插件不会复制宿主导航。
2. 使用站点真实图标和现有 Material 图标，不使用参考图中的示意品牌图案。
3. 缺失种子按下载器 / hash 监控，详情提供维护入口；不会给每个站点虚构一个“缺失种子正常”结果。馒头检查只出现在适用站点。
4. 加入服务器时区、修复确认、复制诊断及真实未检测状态，以适配实际管理工作。
